# 6. 前端设计文档

## 6.1 页面结构

```
小程序页面树
├── pages/index/          # 首页：包裹列表（默认着陆页）
├── pages/bind/           # 账号绑定
├── pages/detail/         # 包裹详情与轨迹时间线
├── pages/settings/       # 设置与通知管理
└── pages/stats/          # 数据统计
```

## 6.5 微信订阅消息设计

### 模板定义

需要在微信小程序管理后台申请两个订阅消息模板：

| 模板 | 字段 | 示例 |
|---|---|---|
| **包裹到达通知** | 快递公司、运单号、到达城市、到达时间 | 中通快递 / 7730***789 / 上海市 / 06-23 14:00 |

```
用户首次打开小程序
```

## 6.6 全局状态管理

使用小程序原生 getApp() + 全局数据，不引入第三方状态管理。

```javascript
// app.js
App({
  globalData: {
    user: null,          // 用户信息
    bindings: {},        // 平台绑定状态 { pdd: 'active', jd: 'not_bind', ... }
    settings: {},        // 用户设置
    currentPage: 1,      // 包裹列表页码
    hasMore: true        // 是否有更多数据
  },
  
  // 工具方法
  refreshBindings() {},
  refreshSettings() {}
})
```

## 6.7 关键交互细节

### 下拉刷新
- 使用小程序原生 `enablePullDownRefresh`
- 刷新时重新请求包裹列表 + 账号绑定状态

### 加载更多
- 滚动到底部自动加载下一页
- 使用 IntersectionObserver 或 `onReachBottom`

### 错误处理
- 网络错误 → 显示轻提示 "网络错误，请稍后重试"
- 数据为空 → 显示对应引导文案
- 操作失败 → 显示错误原因

### 弱网适配
- 请求超时设置 10 秒
- 加载状态骨架屏
- 关键操作（绑定/删除）有 loading 状态
